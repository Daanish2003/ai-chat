Review checks

  • Is the new code in the package that owns that kind of decision? Rules → api. Drawing → chat-react. Pure client logic → chat-core.
  • Does any new import point up, or close a cycle?
  • Does an api file that the browser imports (chat/sources.ts, chat/models.ts, credentials/services.ts, attachments/kinds.ts) now import db or Node-only code?
  • Does a route in apps/web contain logic that belongs in api?
