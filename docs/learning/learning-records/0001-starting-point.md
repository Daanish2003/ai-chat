# Starting point: almost no knowledge of the chat code

On 2026-10-08 the learner said they know almost nothing about how the chat code works, even though the repo, its specs and its ADRs exist. They want all of it: to change it, review it, explain it and extend it. So the course starts with the package map and the send path before the deeper design ideas (tree, runs, boundaries), and it assumes no knowledge of TanStack AI, oRPC or Drizzle.

**Implications:** define every library term on first use; don't assume the learner has read the ADRs yet. Lessons should point into the ADRs rather than re-teach them as prose.
